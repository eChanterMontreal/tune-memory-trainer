# Tune Memory Trainer

App para memorizar el arranque (2 compases) de las tunes, de oído y leyendo la partitura.

## Agregar una tune nueva
1. Entra a este repositorio en github.com → carpeta `tunes/`.
2. **Add file → Upload files** → arrastra el `.bww` → **Commit changes**.
3. Espera ~1 minuto y vuelve a abrir la app: la tune aparece sola.

No hace falta tocar `index.html` ni ninguna lista (`tunes/index.json` es solo un respaldo).
Para quitar una tune, borra su `.bww` de la carpeta.
